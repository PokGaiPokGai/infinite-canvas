# Krita 与无限画布：自动读取、新图写回和通用生成

两个应用各自打开。Krita 插件在 Krita 进程内提供本机连接，不启动另一套 ComfyUI，也不打开无限画布。画布入口只准备自身服务；需要读取本机生图参数时才复用或调用已有 ComfyUI 启动器。

## 首次启用

保存作品并关闭 Krita 后，在仓库根目录运行 `powershell -NoProfile -ExecutionPolicy Bypass -File local/Install-KritaBridge.ps1`。安装器只添加独立的 `infinite_canvas_bridge` Python 插件并启用对应设置，不修改 AI Diffusion、其他插件、模型或作品。

安装器创建两份只留本机的连接配置：仓库 `.local/krita-link/connection.json` 和 Krita 资源目录的 `infinite_canvas_bridge.json`。它们含随机连接令牌，不是配置模板，不得加入 Git 或发给别人。已有不兼容配置不会被静默覆盖。原 Krita 设置文件留在被忽略的 `.local/before-krita-v1-20261022/`，不复制到源码或文档。

之后照常分别打开 Krita 与 Infinite Canvas，任意先后都可。读取模式默认仍为手动；绑定文档后可单独开启 Auto。读取小面板的「Auto 停笔等待（秒）」按节点保存等待时间，默认 2 秒，支持大于 0 的小数，回车或离开输入框时保存；它调节停笔后的等待时间。Auto 在 Krita 输入停止并达到该时间后检查绑定画面，像素未变就不保存新快照，不会自动生图；单独的 Auto 读取更新也不会触发写回。自定义等待需要配套更新本机 Node 桥接和 Krita 连接插件；更新插件前保存画稿并关闭 Krita，保留现有连接配置，重新打开后生效。

## 操作

1. 在创建菜单添加「Krita Link」。直接在节点卡片上选择「读取」，再选文档和「选择图层」（可见图层合成或指定图层），选择后刷新一次画面；节点右下角的渐变旋转箭头可手动再读一次。如需绘画停顿后更新，在节点右下角开启 Auto，并在读取小面板调节停笔等待秒数。右侧输出接口提供最近一次成功读取的图片。图片出现后，整个节点随图片宽高比调整，拖动角点仍保持比例。
2. 添加通用「生成配置」，切到生图，连接 Krita 读取节点；需要风格图时把普通图片拖入画布并连到生成配置，在连线上标「风格」。提示词、模型及 ComfyUI 改绘参数都在生成配置内设置。旧「Krita 预设生成」不再作为新建入口。
3. 生成配置的右侧输出接口在空白时就能连接到下游。点击「开始生成」后，一张成功结果自动成为输出；本轮成功多张时先在节点里选一张候选，才更新输出。未选候选、失败或取消时，上次选定图片仍可显示和手动使用，但不算新的自动写回输入。
4. 再添加一个「Krita Link」，直接在卡片上切到「写入」，把生成配置的输出接入它。明确选择目标文档和目标绘画图层，可以在指定层上方新建结果层，也可以选择覆盖指定层；新建时须选参照图层，没有独立的「顶层」选项。读取和写回的图层列表都按 Krita 面板从上到下的顺序排列，包括组内图层。默认复用流程是首次新建结果层，后续新图写入覆盖该结果层。尺寸不同时须明确选择缩放副本，原图保留；写入不会自动保存 `.kra`。
5. 生图仍需手动点击。目标已配置后，生成配置产出新图、手动选择多图结果或新连入已有图片，会各写回一次；刷新不会重复写回，单独的 Krita Auto 读取更新不触发写回。写回失败或结果待确认时，到节点面板检查并以同一指令手动重试；重试沿用冻结时的原目标。Krita 断线时 Auto 读取每 10 秒重试；关闭 Auto 后保留最后一次成功的图片。

每个 Krita Link 实例一次只执行一种读写动作：读取向右输出固定快照；写回从左接收一张图片，写入成功后还会从右侧传出同一张原图。可直接在卡片上切换模式，已有连线会保留；当前模式不支持的端口及其连线暂时置灰、不参与执行，切回支持该端口的模式后连线自动恢复。已有绑定时切回读取会刷新一次；切换模式不会自动生成或写回。正在执行或待确认的写入指令仍锁定模式，须先完成或明确放弃该指令。写入目标绑定所选文档／图层，不跟随 Krita 当前活动文档。若选择覆盖，插件先备份目标图层；备份后用户又画了新笔触时，写回会被拒绝并保留原图层。

## 通用多参考连法（第一版）

1. 在读取模式的「Krita Link」中绑定文档并取得快照，需要时点击节点右下角刷新箭头，再创建通用「生成配置」节点，选择「生图」和需要的生成渠道，将 Krita Link 连到生成配置。也可以直接创建普通图片节点并连入；把一张或多张图片文件拖到生成配置节点上，会建立图片节点和连线。
2. 点击每条图片连线上的用途标签，选择「参考」「构图」「风格」「配色」「角色」「材质」「姿态」「深度」或「蒙版描述」，可补充一句具体要求。生成配置会显示已读取图片的用途；图片按连接顺序编号，提示词可以明确写「图 1 保留构图、图 2 只参考风格」。
3. 在生成配置中填写提示词与参数，确认渠道后手动点击「开始生成」。用途和补充说明会按图片编号加入提示词，结果节点记录本次参考图片和用途。重新读取 Krita 画面只更新该输入的当前图片，不会自动发起下一次生成。若选择本机 ComfyUI 模型，生成配置的「Comfy 参数」可切换草稿转绘／保留结构细化预设，并调节改绘强度、步数、CFG、种子、采样器、调度器、负面提示词与风格权重。

连线用途首先是给生成渠道的意图说明，不保证所有渠道都有对应的模型控制。当前仓库通用 ComfyUI 脚本把一张「参考」或「构图」图片作为改绘底图，把一张或多张「风格」图片交给已安装的 SDXL IP-Adapter；风格权重由这些图片均分。其他图片角色目前没有相应 ComfyUI 控制节点，会在提交前明确报错，不能当成 ControlNet 或像素级蒙版。无底图仍可文生图。其他已配置生图渠道按各自能力接收参考图；Codex 多图实际效果尚未验收。Blender 视口输入节点尚未实现，今后可作为另一种图片来源接入通用生成配置。

## 数据与边界

- Krita 快照与旧专用任务记录保存在 `.local/krita-link/`；通用生成结果、画布与原图由既有共享媒体存储保存。图片 base64 不写入画布节点记录；节点使用可恢复的存储键，不依赖临时 Blob 地址。
- Auto 不在后台定时抓取图片。Krita 插件监听本机输入结束，按各节点的停笔等待时间发出变化通知；续笔重新计时，按笔期间不读取。画布以最长 60 秒的连接保活等待通知，保活不会提前消耗尚未达到等待时间的事件；像素摘要相同就跳过 PNG 编码与保存。每个画布同一时刻仅一个窗口负责 Auto 保存；该窗口为各 Auto 节点独立等待，快照读取仍依次执行，另一窗口等待接管。Krita 界面中的其他点击也可能触发一次像素检查，但画面不变不会新增快照。持续变更会保存多个本机快照，当前没有自动清理历史快照。
- Krita Link 写入模式把冻结的输入 PNG 和指令回执保存在被 Git 忽略的 `.local/krita-link/returns/`。覆盖图层前还会存 `<commandId>.before.png` 备份，并绑定原图层像素摘要；真正覆盖前再次比较，若你在备份后继续绘画则拒绝写入。写入后像素校验失败时会尝试恢复原像素；备份仍须保留供手动恢复。这些文件可能含画稿，不能上传 Git。重试同一指令不会重新选目标或重做备份。后续覆盖默认结果层前还会比对上次写入的图层像素；若用户已修改该层，自动写回会暂停并保留本机备份。旧画布保存的结果层若缺少该像素摘要，自动覆盖会暂停，须改成每次新建或在面板中手动确认一次写回。
- 原生连接只监听 `127.0.0.1:3003`，验证私有令牌并拒绝浏览器 Origin。网页通过画布同源 `/krita-link` 访问本机 Node 服务；不开放任意网址、文件路径或工作流执行。
- 完整画面读取使用 Krita 的画面投影；单图层读取支持与文档色彩空间一致的 `RGBA / U8 / sRGB-elle-V2-srgbtrc.icc` 和 `GRAYA / U8 / Gray-D50-elle-V2-srgbtrc.icc`，将图层像素转换为画布可用的 PNG 快照，不修改原作品。灰度单层直接映射成 RGB，未做精确 ICC 白点转换，色值可能与 Krita 略有差异；其他图层色彩空间会明确拒绝。写回仍只支持 `RGBA / U8 / sRGB-elle-V2-srgbtrc.icc`。覆盖只针对自身和父级均未锁定、非动画、色彩空间一致的普通绘画图层；写入后会标记 Krita 文档已修改，你仍需自行保存 `.kra`。通用 ComfyUI 脚本还没有选区蒙版、ControlNet、姿态／深度等角色的真实控制节点。
- 快照绑定当前 Krita 会话中的原文档。关闭文档、重启 Krita 或改变尺寸／色彩空间后，旧回传会被拒绝。重新连接后请重新选文档并读取；旧结果仍可下载、手动导入，不能把文件名相同视为同一个文档。
- 通用 ComfyUI 脚本无风格图时继续使用基础节点；连接风格图时复用本机已有的 SDXL IP-Adapter 扩展、模型与 CLIP Vision 模型，不自动安装或更新。切换参数预设保留提示词，采样参数改用该预设默认值；模型失效时要求重新选择，不静默换模型。已有共享渠道保存的旧脚本不会自动变更，需在模型配置中单独更新。
- Codex 渠道复用既有调用方式，不能保证固定底层图像模型或精确输出尺寸。只有明确选择该渠道并点击生成才提交；读取 Krita 和切换节点不消耗生成额度。
- 关闭窗口后的服务生命周期沿用现有本机部署；停止入口保留共享 ComfyUI。连接组件随 Krita 关闭退出，不是 Windows 常驻服务或开机自启项。
